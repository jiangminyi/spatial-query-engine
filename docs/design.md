# 设计说明

## 数据结构与不变量

每个 ID 恰好对应一个不可变 `SpatialItem<T>` 记录，每个存储点恰好属于 `floor(position / cellSize)` 对应的桶。桶不存在重复 ID，也不会保留空集合。更新先验证新坐标所属单元，再修改旧桶和新桶。参数错误不会破坏旧位置；内存耗尽等进程级异常不提供事务保证。

查询返回新的只读列表，列表中的点记录不会随后续更新或删除改变。但 T 可以是可变引用类型，其内部对象由调用方管理；本库不做载荷深复制。

## 网格与全量扫描的选择

矩形查询计算闭区间两端的单元坐标。桶是半开区间，但闭区间的右端恰好落在新桶边界时仍需查该桶。负坐标必须用 floor，不能向零截断。

单元坐标域固定为 [-10^9, 10^9]，使最大二维查询面积小于 Int64 上限。查询边界可以超出存储域，先钳制再计算面积；几何过滤仍使用原始查询条件，所以钳制不会将域外查询误报为匹配。

面积大于 `MaxQueryCells` 或大于存储点数量时选择全量扫描，否则查桶。后者是简单成本估算，不是性能最优保证。查询返回计数便于观测退化；此实现没有未经测量的吞吐量承诺。

## 圆形距离的数值处理

直接算 dx² + dy² 会溢出。先检查每个轴的差是否超过半径，再按半径的二进制指数同时缩放 dx、dy、radius；缩放后半径位于 [1, 2)，平方安全。二次幂缩放比逐分量除以半径更能保留原有二进制比例，测试中的勾股整数边界不会因除法舍入被错误排除。

计算中心 ± 半径时可能溢出为无穷，查询边界会安全钳制。候选包围盒外扩一个 ULP，降低加减舍入导致漏掉边界候选的风险，最终仍用距离谓词过滤。对极小量和接近极限的 double 值依然遵循浮点舍入，不承诺数学实数的精确谓词。禁止 NaN 与无穷输入，也不接受负半径。

## 复杂度

添加、更新、删除平均 O(1)，取决于 Dictionary/HashSet。网格查询为 O(C + K + M log M)，C 为访问单元数、K 为候选数、M 为结果数；全量扫描为 O(N + M log M)。稳定排序是有意加入的额外成本，便于重放和验证。空间 O(N + B)，B 为非空桶数。单桶聚簇无法得到加速。

## 独立验证

暴力模型仅维护 ID 字典，不使用网格、候选选择或被测过滤函数。随机坐标取半整数，参考圆判定直接使用安全范围内的平方距离。四种单元尺寸覆盖稀疏、密集及频繁跨桶移动。独立模型首先发现按半径归一化的边界漏报，修复为二次幂缩放后增加了四组勾股边界回归规格。

进一步扩展可考虑对象 AABB、分层网格、只读查询快照和并行读；这些会引入多桶重复去重、快照代际及写入同步问题，当前实现没有隐含提供这些保证。
